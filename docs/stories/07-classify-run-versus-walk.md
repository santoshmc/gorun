# User Story: 7 - Count Only Runs Towards My Goal

**As a** runner,
**I want** walks and other activities excluded from my running goal,
**so that** my progress reflects genuine running distance.

## Acceptance Criteria

*   Each imported activity is auto-classified as run or walk (or other) using the provider's activity type and pace/speed data.
*   Only activities classified as runs count towards the monthly and weekly distance goals.
*   Walks and other activities are still visible in the activity history, clearly labelled and excluded from goal totals.
*   The classification for each activity is visible to the runner.

## Notes

*   Transcript: "The area where I run has to calculate only the run, not the walk or the other things."
