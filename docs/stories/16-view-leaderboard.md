# User Story: 16 - Compete on a Leaderboard

**As a** runner,
**I want** to see how my distance compares with my friends and coworkers,
**so that** friendly competition keeps me motivated.

## Acceptance Criteria

*   A leaderboard ranks connected friends by total run distance for a selectable period (week or month).
*   The runner's own position is always visible, even when outside the top of the list.
*   Only activities classified as runs count towards leaderboard ranking.
*   The runner can opt out of appearing on leaderboards, in which case they are hidden from others' boards.
