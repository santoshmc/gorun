# User Story: 12 - Build and Maintain a Running Streak

**As a** runner,
**I want** the app to count my consecutive completed planned runs as a streak,
**so that** I stay motivated to keep my habit going.

## Acceptance Criteria

*   A streak counter increases for each consecutively completed planned run day.
*   Rest days in the plan do not break the streak.
*   Missing a planned run day resets the current streak to zero.
*   Both the current streak and the longest streak achieved are displayed.
*   The streak value updates when an activity is imported, added manually or reclassified.

## Notes

*   Streaks underpin the badge and sharing features (Stories 13 and 15).
