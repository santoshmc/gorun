# User Story: 10 - Track My Weekly Progress

**As a** runner,
**I want** to see my progress against the weekly target across the week,
**so that** I know whether I need to make up distance before the week ends.

## Acceptance Criteria

*   A weekly view shows each day of the week with planned versus actual distance and its completion state.
*   Total distance run so far this week and remaining distance to the weekly target are displayed.
*   At the end of the week the week is marked as achieved or missed against the weekly target.
*   Previous weeks in the goal month can be viewed.

## Notes

*   Transcript: "We should be able to track the progress of the user across the week."
