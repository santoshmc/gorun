# User Story: 14 - Invite Friends to Join Me

**As a** runner,
**I want** to invite friends and colleagues to the app,
**so that** I can run alongside people I know.

## Acceptance Criteria

*   An invite can be sent via a shareable link, by email, or by selecting entries from an imported contact list.
*   Contact import requires explicit consent and only uses contacts the runner selects.
*   The runner can see the status of sent invites (sent, accepted).
*   An accepted invite connects both people so they can appear in each other's leaderboards.
*   Contacts can be removed and imported contact data deleted on request.

## Notes

*   Transcript: "The app should also have the option to invite friends, upload contacts".
*   Contact handling must comply with data protection rules; store only what is needed to send invites.
