# User Story: 19 - Use the App Comfortably on My Phone Browser

**As a** runner,
**I want** the app to work well in my phone's browser,
**so that** I can plan and check my runs on the move without installing anything.

## Acceptance Criteria

*   All MVP screens (goal setup, plan, daily/weekly/monthly progress, activity list) are usable on common mobile screen widths without horizontal scrolling.
*   Tap targets and text remain legible at mobile sizes.
*   The same screens adapt to desktop widths.
*   Core screens load and remain usable on a typical mobile network connection.

## Notes

*   Transcript: "Let's start with the mobile web version and then scale it up to a mobile app."
*   This is the MVP delivery platform; native app is a later phase.
