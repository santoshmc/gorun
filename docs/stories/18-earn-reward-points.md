# User Story: 18 - Earn Reward Points for My Running

**As a** runner,
**I want** to accumulate reward points based on the distance I run,
**so that** I get tangible value from staying active.

## Acceptance Criteria

*   Points are awarded according to a published rule based on verified run distance.
*   A rewards screen shows the current point balance and the transactions that produced it.
*   Only runs (not walks or corrected-out activities) earn points.
*   Available rewards or partner offers are listed with the points required.
*   Point totals are recalculated if an activity is deleted or reclassified.

## Notes

*   Transcript mentions tying up with SG Sports and partner/sponsor reward or cashback schemes.
*   Actual partner redemption integration is a separate future story.
