# User Story: 9 - See Whether I Hit Today's Planned Distance

**As a** runner,
**I want** each planned day to be marked complete or incomplete based on what I actually ran,
**so that** I get immediate feedback on whether I am keeping to my plan.

## Acceptance Criteria

*   Each planned day shows the planned distance, the actual run distance and a completion indicator.
*   A day is marked complete (check mark) only when actual run distance meets or exceeds the planned distance for that day.
*   A day where the runner fell short shows as incomplete, with the shortfall displayed (e.g. "4 km of 5 km").
*   Rest days are shown as rest, not as failures.
*   Completion status updates automatically when new activities are imported or corrected.

## Notes

*   Transcript: "today he or she has done 5 km. Yesterday, he did only 4, so he doesn't get a check mark."
