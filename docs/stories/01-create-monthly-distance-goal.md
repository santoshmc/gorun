# User Story: 1 - Create a Monthly Running Distance Goal

**As a** runner,
**I want** to set a monthly running distance target (e.g. 100 km),
**so that** I have a clear, measurable objective to work towards.

## Acceptance Criteria

*   A goal can be created by entering a target distance and selecting the calendar month it applies to.
*   Distance unit (km or miles) can be selected and is used consistently across the app.
*   Only one active monthly distance goal exists at a time; creating a new one for the same month replaces the previous target after confirmation.
*   The saved goal is visible on the runner's home/dashboard screen immediately after creation.
*   An existing goal can be edited or deleted before the month ends.

## Notes

*   Monthly distance is the anchor goal from which weekly and daily plans are derived (see Story 2).
*   Transcript example: "if a user had a plan to run, say, 100 km a month".
