# User Story: 3 - Customise My Generated Run Plan

**As a** runner,
**I want** to manually adjust the suggested distances and run days in my plan,
**so that** the plan fits around my real-life schedule and fitness level.

## Acceptance Criteria

*   Individual day distances in the plan can be edited.
*   Run days can be moved to different days of the week, and days can be marked as rest days.
*   The app shows the running weekly and monthly totals as edits are made, and warns when the totals no longer match the goal.
*   The runner can accept a mismatch (negotiated plan) or reset the week back to the generated suggestion.
*   Changes are saved and reflected on the dashboard and in tracking.
