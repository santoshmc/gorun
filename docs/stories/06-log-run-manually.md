# User Story: 6 - Log a Run Manually

**As a** runner without a connected device,
**I want** to enter a run manually,
**so that** I can still use the app and keep my plan progress accurate.

## Acceptance Criteria

*   A run can be added by entering date, distance, duration and activity type.
*   Pace and average speed are calculated automatically from distance and duration.
*   Manually entered runs count towards daily, weekly and monthly progress in the same way as imported runs.
*   Manual entries are visually marked as manual in the activity list.
*   Manual entries can be edited or deleted.

## Notes

*   Important for MVP mobile web where no automatic source may be connected.
